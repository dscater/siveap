3) Instalar librerías para usar Modelo Lineal General (GLM) con Poisson
 pip install fastapi uvicorn pandas statsmodels numpy

	fastapi: Para crear Api's consumibles en Python
	uvicorn: Servidor que usara fastapi
	pandas: manipular datos/tablas
	statsmodels: librería para el manejo de estadísticas (aquí se usara GLM con Poisson)
	numpy: para el calculo matemático de los datos (matrices, transforamciones, cálculos)
